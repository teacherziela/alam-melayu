# HistoryVerse 360 RPG 3D — Bab 1 Kerajaan Alam Melayu

Prototaip 3D menggunakan Three.js, sesuai untuk GitHub Pages. Buka `index.html` melalui pelayan web atau GitHub Pages (memerlukan internet untuk memuatkan Three.js).

## Fungsi
- Dunia 3D, rumah, pokok, jalan, pendekar, NPC.
- Empat misi Bab 1 Sejarah Tingkatan 2, soalan dan maklum balas.
- WASD / anak panah atau butang sentuh; E / Bercakap untuk interaksi.
- XP dan kemajuan disimpan dalam `localStorage` pada peranti yang sama.

## Had versi pertama
- Model watak dan bangunan ialah geometri 3D ringkas, bukan aset animasi profesional.
- Tiada akaun murid atau pangkalan data PBD guru; rekod setempat bukan bukti PBD berpusat.
- Soalan adalah contoh awal dan boleh diperkemas mengikut buku teks.

## GitHub Pages
Upload `index.html` dan `README.md` ke repositori baharu, kemudian Settings > Pages > Deploy from a branch > main / root.
